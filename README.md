# n8n-nodes-megabrain

An [n8n](https://n8n.io) community node for [MegaBrain](https://getmegabrain.com): generate images and videos and call 100+ text models through one pay-as-you-go API key.

- **Images**: Nano Banana Pro, Nano Banana 2, FLUX 2, FLUX.1, Seedream 4.5, MiniMax H3 — text-to-image and edits.
- **Videos**: Kling 3 (standard and pro), Kling 2.6, Seedance 2.5 — text-to-video and image-to-video.
- **Text**: Claude, GPT, Gemini, Kimi, GLM, Qwen, DeepSeek, Grok and more, plus the free `mb-auto/free`.

The model lists load live from the API, with prices. Failed image and video jobs are refunded automatically.

## Installation

Follow the [community nodes installation guide](https://docs.n8n.io/integrations/community-nodes/installation/): in n8n open **Settings → Community Nodes → Install** and enter `n8n-nodes-megabrain`.

## Credentials

1. Sign in at [getmegabrain.com](https://getmegabrain.com), add funds on the [Balance](https://getmegabrain.com/credits) page and copy your key on the [API key](https://getmegabrain.com/keys) page.
2. In n8n create a **MegaBrain API** credential and paste the key. Leave **Base URL** as it is.

The credential test calls `GET /key`, so a wrong key shows up right away.

## Operations

| Resource | Operation | What it does |
| --- | --- | --- |
| Image | Generate | Submits a job to `POST /queue/{model}`, waits for it and returns the image URLs (and the file, with **Download File** on). Edit models take **Image URLs**. |
| Video | Generate | Same for video: prompt, optional **Start Image URL** (required by image-to-video models), duration and sound. |
| Text | Message a Model | OpenAI-compatible `POST /chat/completions` with a system message, temperature, max tokens and JSON output. |
| Job | Get Status / Get Result | Checks a job submitted with **Wait for Result** off, by its `request_id`. |

Friendly options (aspect ratio, resolution, number of images, seed, output format, negative prompt) go to the model under the field name it takes: for example **Aspect Ratio 16:9** becomes `aspect_ratio` for Nano Banana and `image_size: landscape_16_9` for FLUX. An option the chosen model does not take is left out and named in `skipped_options`. Anything else goes in **Extra Parameters (JSON)**; every model's fields are listed in the [media API docs](https://getmegabrain.com/docs/media#params).

Output of a finished job:

```json
{
  "request_id": "6c1f…",
  "model": "nano-banana-pro",
  "status": "COMPLETED",
  "url": "https://…/image.png",
  "urls": ["https://…/image.png"],
  "output": { "images": [{ "url": "https://…/image.png" }] }
}
```

If a job runs longer than **Timeout**, the node stops with the request ID; the job keeps running and **Job → Get Result** fetches it later. The node can also be used as a tool by n8n's AI Agent.

## Workflow templates

[`templates/`](templates) has ready workflows that use only the built-in **HTTP Request** node, so they also work on n8n Cloud without installing this package:

| File | What it does | Models |
| --- | --- | --- |
| [telegram-image-bot-nano-banana-pro.json](templates/telegram-image-bot-nano-banana-pro.json) | Telegram bot: message in, 2K image out | Nano Banana Pro |
| [text-to-video-kling-3.json](templates/text-to-video-kling-3.json) | Form idea → prompt → video link | Kling 3, mb-auto/free |
| [instagram-carousel-flux-2.json](templates/instagram-carousel-flux-2.json) | Topic → carousel slides + caption | FLUX 2, mb-auto/free |
| [product-photo-to-video-ad.json](templates/product-photo-to-video-ad.json) | Product photo → lifestyle shot → vertical video ad | Nano Banana Pro Edit, Kling 3 |
| [ai-agent-any-model.json](templates/ai-agent-any-model.json) | AI Agent on any MegaBrain text model via the OpenAI Chat Model node | mb-auto/free and 100+ more |

Import one with **Workflows → Import from File**. They expect a **Header Auth** credential named `MegaBrain API key` (header `Authorization`, value `Bearer YOUR_KEY`); the AI agent template expects an **OpenAI** credential with Base URL `https://getmegabrain.com/api/gateway/v1`. The files are generated by `scripts/build-templates.py templates`.

## Compatibility

Built and tested with n8n 2.48 and `@n8n/node-cli` 0.57. Requires n8n 1.0 or later.

## Development

```bash
npm install
npm run lint
npm run build
npm run dev   # starts n8n at http://localhost:5678 with this node loaded
```
